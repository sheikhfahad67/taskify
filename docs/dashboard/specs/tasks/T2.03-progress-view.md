# T2.03 — The progress view shows the board, waves, run state, log and live subagent activity, updating live

## Objective

`#/plan/<id>/progress` shows, from `/api/plan`:

- **Run header** — run state, current task, current step, last updated, resume note (or "No run yet"
  when there is no PROGRESS.md).
- **Waves row** — one chip per task per wave, coloured by status.
- **Board** — columns `pending`, `in_progress`, `in_review`, `changes_requested`, `blocked`, `done`,
  `skipped`, plus `other` for any unknown status; one card per spec with id, title, `AC x/y`,
  verdict, and `fix N` when N > 0.
- **Live activity** — open subagents (a `SubagentStart` with no later `SubagentStop` for the same
  `aid`) with their type and latest tool `sum`; then the last 30 events newest first. If no tool
  events exist at all, the panel shows subagents only (the `05` fallback) without an error.
- **Log** — PROGRESS.md log rows, newest first.

With Live on, a status change on disk shows on the board within one poll (~3 s) with no reload.
