# T4.02 — taskify --dashboard starts the dashboard (public with --public), and a revision resolves the comments it addressed

## Objective

`/taskify:taskify <what> --dashboard` writes the plan set as before and then starts the dashboard
locally (`cli.mjs start`), ending its report with the URL. With `--public` (which implies
`--dashboard`) it runs `cli.mjs start --public` instead and reports the public URL with the same
warning `/taskify:dashboard` prints, or the local URL plus the CLI's install hint when no tunnel
tool is available. Without `--public` it never opens a tunnel. It never asks
anything (it is `context: fork`, U1). When taskify is asked to revise a plan folder that already
has `<plan>/.taskify/review.json`, it reads open comments with `cli.mjs review`, addresses them in
the docs, and marks each addressed comment resolved with
`cli.mjs resolve --by taskify --note "<what changed>"`. Comments it did not address stay open and
are listed in its report.
