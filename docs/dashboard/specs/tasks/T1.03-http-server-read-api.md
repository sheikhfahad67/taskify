# T1.03 — server.mjs serves the read API on 127.0.0.1 behind a mandatory token, with path safety

## Objective

`node dashboard/server.mjs --root <dir> --port 0` (token from `TASKIFY_DASHBOARD_TOKEN`) starts an
HTTP server bound to `127.0.0.1` that answers the GET routes of `01` §3 — `/`, `/static/<file>`,
`/api/health`, `/api/plans`, `/api/plan`, `/api/file` — and `401`s every request without the token.
It reads from disk on every request, keeps the last good parse when a file is half-written, never
lets `/api/file` leave a plan folder, writes `<root>/.taskify/dashboard.json` once listening, and
exits after the idle timeout, removing that file.

## Scope

### Create
- `dashboard/server.mjs` — flags `--root` (default cwd), `--port <n>` (exact; `0` = OS picks) or
  `--port-start <n>` (try n … n+9), `--idle-minutes <n>` (default 240, fractions allowed). Missing
  `TASKIFY_DASHBOARD_TOKEN` → print an error to stderr, exit 2. Implements every GET route and every
  "Auth and safety rule" in `01` §3, including the per-path last-good cache. Last-good rule: if a
  spec now parses with no `id` or no `status` but the cached result had them, return the cached
  result; same for PROGRESS.md with no `run_state`. After `listen`, writes `dashboard.json` (`01`
  §2a, `tunnel: null`). On idle exit: read `dashboard.json`, kill `tunnel.pid` if set (ignore
  errors), delete `dashboard.json`, exit 0. Uses `parse.mjs` and `review-store.mjs` (for the
  `review` field). Imports only `node:` modules and those two libs.
- `dashboard/public/index.html` — minimal valid shell: `<title>Taskify Dashboard</title>`, a
  `<main id="app">`, and `<script type="module" src="/static/app.js"></script>`. T2.01 fills it out.
- `dashboard/test/server-read.test.mjs` — tests named below.

### Edit
- `dashboard/test/helpers.mjs` — add `startServer(root, { idleMinutes, portStart } = {}) → { port, token, url, child, stop() }`
  (spawns `process.execPath dashboard/server.mjs` with a fresh token in the env, waits for
  `dashboard.json`, reads the port) and `get(url, { token, cookie, headers })` / `post(...)` thin
  `fetch` wrappers.

### Explicitly out of scope
- POST routes — T1.04. CLI (`start`/`stop`, detaching, reuse) — T1.05. Tunnel — T1.07.
- Real UI files (`app.js`, `app.css`, views) — T2.01–T2.03. A request for `/static/app.js` may 404 until then.

## Implementation steps

1. Implement routing, auth (cookie `taskify_t` or `Authorization: Bearer`; SHA-256 both sides, then
   `crypto.timingSafeEqual`), the `?t=` → `302` + `Set-Cookie` flow, headers, and the error
   handler that turns any thrown error into `500` without stopping the server.
2. Implement `/api/plans`, `/api/plan`, `/api/file` with `findPlans` allow-listing and the
   `realpathSync.native` containment check.
3. Implement `dashboard.json`, port fallback, idle timer (reset on every request).
4. Tests (exact names): `rejects requests without token`, `query token sets cookie and redirects`,
   `bearer and cookie both authenticate`, `wrong token of a different length is 401`,
   `health reports 127.0.0.1 bind`, `plans lists the fixture`, `plan returns derived task data`,
   `file serves markdown inside the plan`, `file rejects traversal absolute non-md and link escape`,
   `unknown plan is 404`, `security headers on every response`,
   `half-written spec keeps last good parse`, `port-start falls back when the port is taken`,
   `idle exit removes dashboard.json`.
   - The link-escape case creates a directory link inside the temp plan pointing outside it
     (`fs.symlinkSync(target, link, 'junction')` — junctions need no admin rights on Windows) and
     requests `<link>/secret.md`.
   - The last-good case requests the plan, truncates `T1.02-beta.md` to its first 3 lines, requests
     again, and asserts T1.02 still has `status: in_review`.
