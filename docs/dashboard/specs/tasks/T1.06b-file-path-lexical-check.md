# T1.06b — /api/file rejects a path that leaves the plan folder before touching the disk

Inserted after T1.06 at the user's request (2026-10-05), to fix T1.03 review finding R-4 before
T1.07 makes the server reachable through a public tunnel.

## Objective

`GET /api/file` decides whether `path` stays inside the plan folder **lexically first**, with no
file-system call: `path.resolve(plan.dir, p)` must start with `path.resolve(plan.dir) + path.sep`.
Only a path that passes this check reaches `fs.realpathSync.native` and the existing realpath
containment check. A UNC path such as `\\host\share\x.md` or `//host/share/x.md` is therefore
rejected with `404` without the server ever trying to open it, so it cannot trigger an outbound
SMB connection on Windows. All existing `/api/file` behaviour (traversal, absolute, non-`.md`,
link-escape → `404`; valid doc → `200`) is unchanged.

## Implementation steps

1. In `readPlanFile`, compute `const target = path.resolve(plan.dir, p)` and return `null` unless
   `target.startsWith(path.resolve(plan.dir) + path.sep)`. Then run the existing realpath logic on
   `target`.
2. Add the test. It requests, with the token, each of: `\\127.0.0.2\share\x.md`,
   `//127.0.0.2/share/x.md`, `\\?\C:\Windows\x.md`, and the existing traversal case, and asserts
   `404` for each. `readPlanFile` is not exported, so the test works through HTTP only, and it
   also asserts each response arrives in under 1000 ms (an SMB attempt to an unreachable host
   takes far longer on Windows).
3. Run the ACs.

- **Type:** structural
- **Command:**

- **Expected:** the function shows a `path.resolve(...)`/`startsWith(... + path.sep)` check that returns before the first `realpathSync` line
- **Evidence:**
  ```
  function readPlanFile(plan, p) {
    if (typeof p !== 'string' || !p.endsWith('.md')) return null;
    const target = path.resolve(plan.dir, p);
    if (!target.startsWith(path.resolve(plan.dir) + path.sep)) return null;
    try {
      const base = fs.realpathSync.native(plan.dir);
      const real = fs.realpathSync.native(target);
      return real.startsWith(base + path.sep) && real.endsWith('.md') ? fs.readFileSync(real, 'utf8') : null;
    } catch {
      return null;
    }
  }
  ```
