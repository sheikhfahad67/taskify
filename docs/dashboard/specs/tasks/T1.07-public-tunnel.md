# T1.07 — start --public opens a cloudflared or ngrok tunnel, or falls back to local with an install hint

## Objective

`node dashboard/cli.mjs start --public` starts (or reuses) the local server, then a tunnel:
cloudflared quick tunnel if `cloudflared --version` works, else ngrok if `ngrok version` works,
else none. With a tunnel, the output has `"public_url":"https://…"`, the URL still requires the
token, POSTs from the public origin are accepted, and `stop` ends the tunnel. With no tool, the
command prints install hints on stderr, keeps the local server running, prints
`"public_url":null`, and exits 0.

## Scope

### Edit
- `dashboard/cli.mjs` — `start --public`:
  1. Detect with `execFileSync(<tool>, [<version arg>], { stdio: 'ignore', windowsHide: true })` in
     `try`, in the order cloudflared, ngrok. The env var `TASKIFY_TUNNEL_CMD` (a JSON array, e.g.
     `["node","…/fake-tunnel.mjs"]`), when set, replaces detection — used only by tests.
  2. Spawn detached (`stdio: ['ignore', fd, fd]` to `<root>/.taskify/tunnel.log`, `windowsHide`,
     no shell): `cloudflared tunnel --url http://127.0.0.1:<port>` or
     `ngrok http 127.0.0.1:<port> --log stdout --log-format json`.
  3. Poll the log every 200 ms for up to 20 s: cloudflared → first match of
     `https://[a-z0-9-]+\.trycloudflare\.com`; ngrok → the `url` field of the first JSON line that has
     one starting with `https://`. Timeout → kill the tunnel, print a hint, `public_url: null`.
  4. Record `tunnel: { provider, pid, url, cmd: <basename of executable> }` in `dashboard.json`.
  5. With no tool: stderr lines `No tunnel tool found. Install cloudflared:` then
     `  Windows: winget install --id Cloudflare.cloudflared`,
     `  macOS:   brew install cloudflared`,
     `  Linux:   https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/`,
     `Or install ngrok and run: ngrok config add-authtoken <your token>`; then exit 0.
  6. Print a stderr warning whenever a public URL is created:
     `WARNING: anyone with this link can read these plan docs and add comments or approve.`
  `stop` and the server's idle exit kill the tunnel pid only if the process name contains
  `tunnel.cmd` (`tasklist /FI "PID eq <pid>" /FO CSV /NH` on Windows, `ps -p <pid> -o comm=`
  elsewhere, both via `execFileSync`, no shell).
- `dashboard/server.mjs` — only if AC3 shows the tunnel rewrites `Host`: also accept an `Origin`
  equal to `X-Forwarded-Host`. Record in the Completion record which case applied.
