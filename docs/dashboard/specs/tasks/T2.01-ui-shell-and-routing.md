# T2.01 — The dashboard page loads, lists plans, routes to a plan, and polls with a toggle

## Objective

Opening `http://127.0.0.1:<port>/?t=<token>` in a browser shows a page that lists the plans from
`/api/plans` (id, title, done/total, run state). Clicking one goes to `#/plan/<id>/review`; a tab
switches to `#/plan/<id>/progress`. `app.js` lazy-imports `./review.js` or `./progress.js` for the
route and shows a plain "view not available" message if the import fails (those files arrive in
T2.02/T2.03). A "Live" toggle (on by default) re-fetches the current route's data every 3 s. A
DevTools-protocol test helper drives a real headless browser for this and later UI tasks.

  `credentials: 'same-origin'`; on `401` shows "Session expired — open the link with ?t= again"),
  `onPoll(fn)` / poll loop, and the router. Home route renders the plan list. Plan routes render a

### Findings

- **R-1** — **Severity:** Important
  - **Claim:** the 3 s interval starts every poller each tick with no in-flight check; slow `/api/*` responses stack up without limit and older responses can overwrite newer ones.
  - **Evidence:** app.js:57-62; app.js:89-108.
  - **Required fix:** skip a poller while its previous run is pending (busy set in the tick loop).
- **R-2** — **Severity:** Minor — a view that calls `onPoll` after an `await` in `mount()` can register into the next route's set (app.js:48-55, 134, 143). Scope `onPoll` to the route sequence.
- **R-3** — **Severity:** Minor — malformed hash (`%E0`) makes `decodeURIComponent` throw outside the try in `route()` (app.js:82, 144-148).
- **R-4** — **Severity:** Minor — a half-written DevToolsActivePort gives 0/NaN and aborts the launch instead of retrying (browser.mjs:81-84).
- **R-5** — **Severity:** Minor — CDP `send()` has no timeout and pending commands are not rejected on socket close, so a dead browser hangs the suite (browser.mjs:45-52).
- **R-6** — **Severity:** Observation — persistence test relies on `Page.navigate` semantics; could mark the old page explicitly.
- **R-7** — **Severity:** Observation — tests 3–5 depend on test 2 setting the cookie; do `?t=` in `before()`.
- **R-8** — **Severity:** Observation — no test of the poll loop or 401 banner; a network failure is silent; sourceMappingURL 404 only with DevTools.
- **R-9** — **Severity:** Observation — XSS check passed (text nodes / setAttribute / textContent; hrefs always `#/plan/` + encoded id).
