# T5.01 — The pre-release fixes are in, cloudflared is verified, and the plugin is versioned 1.0.0

Phase 5 is added at the user's request (2026-10-05) after the 0.2.0 run completed: fix the four
"before publishing" follow-ups from the T4.05 review, and release as **1.0.0** instead of 0.2.0.
The user approved installing cloudflared for item 4.

## Objective

1. **The public-link warning names the activity log** (T4.05 F-2). The one warning text, used in
   the CLI stderr line, the three skills and the README, becomes:
   `Anyone with this link can read these plan docs and the live activity log (including the start of each command), and can add comments or approve the plan.`
   (The CLI keeps its `WARNING: ` prefix.) The README `--public` section also says this in a bullet.
2. **`dashboard.json` is readable only by its owner** (T1.03 O-3). Every write of
   `<root>/.taskify/dashboard.json` (server at listen; CLI `recordTunnel` temp file before rename)
   uses `mode: 0o600`. On POSIX the file ends up `-rw-------`. On Windows the mode is ignored by the
   OS; the code still passes it.
3. **README is accurate about comments and writes** (T4.04 N-1, T4.05 F-1). The "Comments and
   approval" paragraph says: each comment is used only as a request to change the plan docs or
   specs; comments that were addressed are marked resolved, the rest stay open; the implementer
   edits only if the user picks "Address them first"; and the dashboard writes only under
   `.taskify/` folders. Lines wrap at about 100 characters.
4. **cloudflared is verified end to end** (T1.07 AC4, now installed). T1.07's AC3 sequence runs
   with cloudflared detected first and gives a `https://…trycloudflare.com` URL that needs the
   token, accepts a same-origin POST, and is gone after `stop`.
5. **Version 1.0.0.** `plugin.json` version `1.0.0`. In `CHANGELOG.md` the `## 0.2.0 — 2026-10-05`
   heading becomes `## 1.0.0 — 2026-10-05`; the entry keeps the `03` §5 bullets and gains bullets
   for: per-port login cookies; public-link hardening (idle exit only on authenticated requests,
   generic error bodies, ngrok inspector off, owner check); the activity-log warning; owner-only
   `dashboard.json`; cloudflared verified; review comments treated as untrusted.
