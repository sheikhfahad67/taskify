# T4.05 — Phase 4 gate — taskify 0.2.0 validates, passes every test, and its dashboard runs from a real session

## Objective

The release candidate is whole: strict validation passes; the full suite passes with nothing
skipped; in a real headless session on this repo, `/taskify:dashboard start` gives a working
tokenized local URL that lists `docs/dashboard`, and `/taskify:dashboard stop` ends it; with no
active run, that session leaves no `events.jsonl` anywhere; and the repo shows no `.taskify/` path in
`git status`.
